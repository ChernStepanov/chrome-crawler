Агент, который доводит дела в браузере

01 · pipeline

Как это работает

Три такта. Агент читает страницу, строит план действий и проверяет результат — вы видите каждый шаг.

example.com/dashboard
┌─────────────────────────────────────┐
│  Прайс-лист          [ Войти ] ←    │
│                                     │
│  Товар       Цена      Наличие       │
│  ─────────────────────────────────── │
│  Виджет A    1 290 ₽    [1] в наличии│
│  Виджет B    2 480 ₽    [2] ожидание │
│  Виджет C      990 ₽    [3] в наличии│
│  → cursor: ищу [ Войти ] ▸          │
│  → click [ Войти ] ◌ ✓            │
│  → форма авторизации открыта         │
└─────────────────────────────────────┘
01 / READ

Изучает страницу

Снимок DOM и скриншот уходят в контекст модели. Агент видит структуру, текст и интерактивные элементы — как разработчик в DevTools.

dom.snapshot() → 1 418 nodes · a11y tree · viewport
02 / ACT

Планирует и действует

Каждое действие — через Chrome DevTools Protocol: клики, ввод текста, скролл, навигация. Курсор идёт к цели, вы видите путь.

cdp.click("Войти") · cdp.type("email", "dev@clodex.ai")
03 / VERIFY

Проверяет результат

После шага агент перечитывает страницу и сверяется с задачей. Если что-то пошло не так — корректирует план сам.

query_dom(".price") → 3 items · assert > 0 ✓

02 · capabilities

Что умеет

Шесть вещей, ради которых панель открывают каждый день. Без магии — только браузерные API и хороший контекст.


        
Управление вкладкой через CDP

        
Клики, ввод текста, скролл и навигация — через Chrome DevTools Protocol. Агент работает с настоящей страницей, а не с облачной эмуляцией.

        
cdp.attach(tab) → real DOM

        
      

      

        

        
Режимы мышления

        
Быстро для одного действия, Авто для обычной задачи, Глубоко для многошаговых планов с самопроверкой на каждом шаге.

        
fast · auto · deep

        
      

      

        

        
Локальные модели

        
LM Studio, Ollama, llama.cpp, Jan, vLLM. Подключите localhost:1234 — и агент работает без выхода в интернет.

        
http://localhost:1234

        
      

      

        

        
Скилы сайтов

        
Сохраните пошаговый сценарий для сайта, которым пользуетесь каждый день. Агент выполнит его целиком по одной короткой команде.

        
skill: gdocs.export → run

        
      

      

        

        
Подтверждение рискованных действий

        
Платежи, удаление, отправка форм — агент спросит прежде, чем нажать. Последнее слово всегда за вами, даже в режиме авто-приёма.

        
risk: payment → confirm

        
      

      

        

        
Палитра под сайт

        
Панель подстраивается под цвета активной вкладки: акцент берётся из интерфейса сайта. Шесть ручных акцентов — в запасе.

        
accent ← site.theme-color

      04 · modes
      
Режимы и модели

      
Один агент — три уровня глубины. Скорость и стоимость отличаются, надёжность остаётся.

    

    


┌──────────┬───────────────┬──────────────┬───────────────┐
│ режим     │ глубина       │ шаги         │ контекст      │
├──────────┼───────────────┼──────────────┼───────────────┤
│ Быстро   │ один вызов    │ 1–3          │ страница      │
│ Авто     │ план + рефлекс │ 4–12         │ + вкладка     │
│ Глубоко  │ дерево планов │ 12–40        │ + история     │
└──────────┴───────────────┴──────────────┴───────────────┘

      
Сравнение режимов мышления: глубина планирования, число шагов на задачу и объём контекста, который агент держит в голове.

Авто · отклик~2.4 s

      05 · q&a
      
Вопросы

      
Коротко о главном. Остальное — в документации.

    

    

      

        Агент видит мои данные?
        
Страница и скриншоты обрабатываются локально в браузере и уходят только провайдеру, которого вы выбрали. Для локальных моделей (Ollama, LM Studio, vLLM) за пределы машины не уходит ничего.

      

      

        Чем это отличается от обычного чат-бота?
        
Чат-бот отвечает текстом. Clodex действует: кликает, вводит текст, заполняет формы и читает результат действий на реальной странице через Chrome DevTools Protocol.

      

      

        Какие модели поддерживаются?
        
Любой OpenAI-совместимый endpoint. Из коробки: OpenAI, Anthropic, Gemini, а также локальные LM Studio, Ollama, llama.cpp, Jan и vLLM — достаточно указать baseUrl и ключ.

      

      

        Что агент делает с оплатами и удалением?
        
По умолчанию рискованные действия требуют подтверждения: панель показывает, что именно будет нажато, и ждёт вашего слова. Порог подтверждения настраивается — от «всегда спрашивать» до «делай сама».

      

      

        Работает ли это на нескольких вкладках сразу?
        
Агент привязан к активной вкладке и переключается вместе с ней. Параллельные задачи — в плане после стабилизации CDP-сессий; сейчас это сознательное ограничение ради предсказуемости.
