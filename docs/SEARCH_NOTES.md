# Поиск товаров и объявлений: заметки

Как делать качественный поиск по маркетплейсам (Авито — сделано; Озон, Wildberries — впереди).
Собрано из живых прогонов на Авито (октябрь 2026). Обновлять после каждого нового сайта.

## Принципы (решено с пользователем)

- **Цель — увидеть как можно больше объявлений.** Модели не даём выбирать «сколько смотреть»: у `extract_items` нет `limit`. Берём до 100, а сколько дойдёт до модели, решает бюджет текста (9000 символов).
- **Чинить кодом, а не уговорами в промпте.** Если модель нарушает формат (пропускает ссылки, пишет абзацем), исправляем детерминированно после неё (`AgentLoop.linkItems`). Промпт держим коротким.
- **Подсказки — по факту.** Пишем модели только когда что-то случилось («скрыто 40 объявлений, они дешевле»), а не правилами заранее.
- **Никаких правок под отдельный сайт или товар в коде.** Знания о сайте (категории, параметры URL) хранятся данными, в заметках сайта.
- **Ложное срабатывание должно быть безопасным.** Пометка заставляет перепроверить, но ничего не выбрасывает сама.
- **Разбор качества — вручную.** Пользователь нажимает «плохо», копирует отчёт и присылает. Самоисправление по оценкам не делаем: долго, рынок РФ, разбираем руками.

## Ошибки, которые уже ловили (не повторять)

1. **Запчасть вместо товара** («рама/руль вместо велосипеда»): в названии есть ключевое слово. Лечится описанием продавца в выдаче и нейтральной пометкой по цене. Категорией сайта, если она есть в URL.
2. **Не самые дешёвые**: список обрезан по длине до сортировки или без неё. Всегда сначала сортировать, потом резать, и говорить, что скрыто.
3. **Нет ссылок в ответе**: модель «забыла» формат. Восстанавливать кодом.
4. **«Ещё» — текст вместо списка**: размытая инструкция «same format». Писать формат строки буквально.
5. **Маленькая выдача (10)**: первый сработавший способ разбора побеждал. Нужны все способы и максимум.
6. **Тихая обрезка `clip(…, 9000)` посреди строки**: модель думала, что видит всё.
7. **Весь список одной строкой** («1) … — 74 900 ₽; 2) …»): панель не видела пунктов, ссылки не ставились. `AgentLoop.listify` разбивает такое перечисление и нумерованные строки на пункты «- …» и выделяет цену, потом `linkItems` ставит ссылки.

## Чек-лист нового маркетплейса (Озон, WB, …)

Перед кодом — живая разведка (`/study` или руками), записать результаты сюда:

- [ ] **Где данные.** JSON-LD / microdata в HTML? Или только SPA и данные в JSON внутри страницы (`__NEXT_DATA__`, `window.__INITIAL_STATE__`, `<script type="application/json">`)? Если второе, нужен четвёртый способ разбора «JSON состояния страницы» (общий, не под сайт).
- [ ] **Ленивая подгрузка.** Сколько карточек в DOM сразу и сколько после прокрутки? Есть ли виртуальный список (карточки удаляются при прокрутке)? Тогда собирать по мере прокрутки и склеивать по ссылке.
- [ ] **Параметры URL:** сортировка по цене, фильтр цены от/до, категория, страница (`page=`, `p=`), регион/город. Записать в заметку сайта (данными), чтобы модель строила URL, а не кликала фильтры.
- [ ] **Цены.** Какую брать: обычная, со скидкой, «с картой банка/сайта», за штуку или за упаковку? Зачёркнутая старая цена не должна стать «ценой». Формат валюты, копейки (у некоторых API цена в копейках — проверить).
- [ ] **Реклама и продвижение.** Помечены ли спонсорские карточки («Реклама», `adv`, `promo`)? Они ломают сортировку «по цене». Помечать в выдаче, не выкидывать.
- [ ] **Дубли.** Один товар у нескольких продавцов, варианты (цвет, размер) с одной ссылкой. Ключ дедупликации: ссылка без параметров варианта?
- [ ] **Наличие и доставка.** «Нет в наличии», «под заказ», срок доставки — в details.
- [ ] **Рейтинг и отзывы.** Есть ли в разметке? Для «лучший по отзывам» нужна `sort: rating`? (сейчас нет — добавить общий вариант, если понадобится).
- [ ] **Антибот.** Как реагирует на фоновый `fetch` (403/429, капча, пустой HTML)? Какой безопасный темп? Если фоновая загрузка не работает, только `navigate` во вкладке.
- [ ] **Регион.** Цены и наличие зависят от выбранного города? Модель должна знать текущий регион (из страницы).

Непроверенные знания (проверить вживую, не верить):
- У WB, по памяти, есть публичный JSON-поиск, а цены там в копейках. Адреса и поля меняются, сверить на живой странице.
- Озон — тяжёлый SPA с сильной защитой от ботов. Скорее всего, только чтение открытой вкладки, без фоновых загрузок. Цена «с Ozon Картой» отличается от обычной.

## Как проверять качество

- **Тесты на фейковом DOM** (`extract-items.test.js`): на каждый живой баг — свой тест с реальной формой данных (названия, цены, порядок).
- **Ручной прогон с типовыми запросами:**
  - «топ 5 самых дешёвых X» — сортировка, обрезка, запчасти;
  - «X до N рублей» — фильтр цены;
  - «лучший X по отзывам» — рейтинг;
  - «X в городе Y» — регион;
  - «Ещё» два раза подряд — без повторов.
- **Что смотреть в логе:**
  - вызвана ли `extract_items` с `sort`;
  - сколько «Found / showing»;
  - есть ли «not shown»;
  - что выкинула модель и почему (её reasoning).
- **Отчёт «плохо»** присылается целиком, разбор по ходу решения. Вывод записывается сюда в «Ошибки».

## Идеи на потом

- Роутер: финальный выбор «что подходит» отдать сильной модели.
- Исправления пользователя («это рама») сохранять уроками сайта (данными).
- Сравнение одного товара на нескольких площадках (Авито + Озон + WB) — общий формат строки уже есть.
- Склейка нескольких страниц выдачи в один список до сортировки (страницы 1–3 → топ дешёвых по всем).
